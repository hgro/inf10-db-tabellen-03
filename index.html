Datentypen und Aufbau der Nutzertabelle

In einer Datenbank werden Informationen nicht einfach irgendwie gespeichert. Für jedes Attribut muss festgelegt werden, welche Art von Information darin stehen darf. Dafür gibt es sogenannte Datentypen.

1. Was ist ein Datentyp?

Ein Datentyp legt fest, welche Art von Werten in einem Attribut gespeichert werden können.

Stell dir vor, InstaHub möchte Informationen über seine Benutzerinnen und Benutzer speichern. Dabei gibt es ganz unterschiedliche Angaben:

  • einen Benutzernamen
  • eine Anzahl von Beiträgen
  • das Registrierungsdatum
  • die Information, ob ein Konto aktiv ist

Diese Angaben unterscheiden sich voneinander. Ein Datum ist beispielsweise etwas anderes als ein Text oder eine Zahl. Deshalb benötigt jedes Attribut einen passenden Datentyp.

2. Verschiedene Datentypen

Die folgenden Datentypen begegnen dir häufig in Datenbanken:

DatentypBedeutungBeispiele
TextSpeichert Buchstaben, Wörter und Zeichen.„Lisa“, „lisa23“, „lisa@mail.de“
GanzzahlSpeichert ganze Zahlen ohne Nachkommastellen.12, 150, 2026
DezimalzahlSpeichert Zahlen mit Nachkommastellen.3,5 oder 19,99
DatumSpeichert ein Kalenderdatum.16.11.2026
UhrzeitSpeichert eine Uhrzeit.08:45
Wahrheitswert (Boolean)Speichert nur zwei mögliche Zustände: wahr oder falsch.aktiv/inaktiv, ja/nein

Warum ist die Wahl des Datentyps wichtig?

Der Datentyp muss zur Information passen. Ein Beispiel: Die Anzahl der Beiträge eines Benutzers wird als Ganzzahl gespeichert. Eine halbe Anzahl von Beiträgen ist schließlich nicht sinnvoll. Ein Benutzername wird dagegen als Text gespeichert. Er kann Buchstaben, Zahlen und Sonderzeichen enthalten.

Achtung: Nicht jede Zahl ist automatisch ein Zahlenwert!
Eine Telefonnummer oder eine Postleitzahl wird normalerweise als Text gespeichert. Mit diesen Angaben wird nicht gerechnet. Außerdem können sie mit einer Null beginnen, die sonst möglicherweise verloren gehen würde.

Für jedes Attribut muss ein Datentyp festgelegt werden. So wird sichergestellt, dass die gespeicherten Werte zur jeweiligen Information passen. (Die Fragezeichen klärst du in Aufgabe 3.)

4. Eine Nutzertabelle für InstaHub planen

Nun soll InstaHub Informationen über seine Benutzerinnen und Benutzer speichern. Dafür benötigen wir eine eigene Nutzertabelle. Überlege zunächst, welche Informationen über einen Benutzer sinnvoll sind. Mögliche Attribute sind: BenutzerID, Benutzername, Vorname, Nachname, E-Mail-Adresse, Registrierungsdatum, Konto aktiv.

Die Tabelle könnte beispielsweise so aufgebaut sein:

Tabelle: Benutzer
BenutzerIDBenutzernameVornameE-Mail-AdresseRegistrierungsdatumKonto aktiv
1lisa23Lisalisa@mail.de10.11.2026ja
2max99Maxmax@mail.de12.11.2026ja
3sara_01Sarasara@mail.de15.11.2026nein

Die BenutzerID dient dazu, jeden Benutzer eindeutig zu unterscheiden. Auch wenn zwei Personen denselben Namen haben sollten, können sie anhand ihrer ID auseinandergehalten werden.

Für jedes Attribut muss außerdem ein passender Datentyp ausgewählt werden. Zum Beispiel:

AttributDatentypBegründung
BenutzerIDGanzzahlDie ID besteht aus einer ganzen Zahl.
BenutzernameTextEin Benutzername kann Buchstaben, Zahlen und Sonderzeichen enthalten.
VornameTextEin Vorname besteht aus Buchstaben.
E-Mail-AdresseTextEine E-Mail-Adresse enthält Buchstaben und Sonderzeichen.
RegistrierungsdatumDatumEs wird ein Kalenderdatum gespeichert.
Konto aktivWahrheitswertDas Konto ist entweder aktiv oder nicht aktiv.

Eine gut geplante Tabelle enthält alle benötigten Attribute und verwendet für jedes Attribut einen passenden Datentyp.

b) Ordne jedem Datentyp seine Bedeutung zu. Ziehe die Karte in das Feld – oder tippe erst die Karte und dann das Feld an.

Aufgabe 2: Datentypen unterscheiden

Hier sind Attributwerte aus der InstaHub-Datenbank durcheinandergeraten. In Klammern steht, zu welchem Attribut der Wert gehört. Sortiere jeden Wert in den passenden Datentyp.

Schau nicht nur auf die Zeichen, sondern frage dich: Rechnet man mit dem Wert? Telefonnummern und Postleitzahlen bestehen zwar aus Ziffern, aber man rechnet nicht mit ihnen – und sie können mit 0 beginnen.

Aufgabe 3: Welcher Datentyp passt?

Wähle für jedes Attribut der Benutzertabelle den passenden Datentyp. Die ersten sechs Zeilen kennst du aus dem Text, danach kommen weitere Attribute dazu.

Aufgabe 4: Datentyp-Detektiv

Ein Mitschüler hat für die InstaHub-Tabelle „Beiträge“ die Datentypen festgelegt. Prüfe jede Zeile: Passt der Datentyp? Wenn nicht, wähle den besseren Datentyp aus.

Aufgabe 5: Begründen

a) Vervollständige die Sätze: Wähle zuerst den Datentyp und dann die passende Begründung.

b) Ein Mitschüler sagt: „Die Postleitzahl besteht nur aus Ziffern, also speichere ich sie als Ganzzahl.“ Erkläre ihm mit eigenen Worten, warum das keine gute Idee ist.

Das sollte in deiner Erklärung vorkommen: Mit Postleitzahlen wird nicht gerechnet (niemand addiert zwei Postleitzahlen). Außerdem gibt es Postleitzahlen, die mit 0 beginnen (z. B. 01067 Dresden). Als Ganzzahl würde daraus 1067 – die führende Null ginge verloren. Deshalb ist Text der passende Datentyp.

Aufgabe 6: Plane eine erweiterte Nutzertabelle für InstaHub

InstaHub möchte mehr über seine Benutzerinnen und Benutzer speichern als bisher – zum Beispiel für Statistiken, für den Kontakt oder für Einstellungen im Profil. Plane und baue eine erweiterte Nutzertabelle.

Anforderungen

  • mindestens 7 Attribute, darunter ein Schlüsselattribut (🔑)
  • für jedes Attribut ein Datentyp – insgesamt mindestens 4 verschiedene Datentypen
  • mindestens 3 Datensätze, deren Attributwerte zum Datentyp passen
  • für jedes Attribut eine kurze Begründung des Datentyps
Denkanstöße:
  • Welche Zahlen zeigt InstaHub im Profil an (z. B. Follower)?
  • Wann hat sich jemand angemeldet – an welchem Tag, zu welcher Uhrzeit?
  • Welche Einstellungen kann man im Profil an- oder ausschalten?
  • Wie kann InstaHub jemanden erreichen?
  • Gibt es etwas mit Nachkommastellen, z. B. ein Guthaben?

Tabelle aufbauen

Trage oben die Attribute ein und wähle darunter den Datentyp. Mit 🔑 markierst du das Schlüsselattribut, mit × entfernst du ein Attribut oder einen Datensatz. Rot markierte Felder passen nicht zum gewählten Datentyp (Datum: TT.MM.JJJJ, Uhrzeit: hh:mm, Wahrheitswert: ja/nein).

Checkliste

    Datentypen begründen

    Begründe für jedes Attribut, warum der gewählte Datentyp passt.

    Ergebnis abgeben

    Kopiere dein Ergebnis (Tabelle, Datentypen, Begründungen und deine Erklärung aus Aufgabe 5b) und füge es dort ein, wo deine Lehrkraft es haben möchte.

    Stark! Deine Nutzertabelle erfüllt alle Anforderungen.
